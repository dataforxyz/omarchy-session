# omarchy-session icon assets

**Saved Grid** is the project mark: a four-window workspace grid with a mint
bookmark representing saved session state.

- `omarchy-session.svg` — canonical full-color vector icon
- `omarchy-session-symbolic.svg` — monochrome/symbolic variant
- `omarchy-session-preview.png` — 1024 px preview
- `icons/png/` — launcher exports from 16 through 512 px

The artwork is part of omarchy-session and distributed under the repository's
GPL-3.0-or-later license.
